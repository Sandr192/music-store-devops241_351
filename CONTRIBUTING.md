# Правила внесения изменений (Contributing)

## Ветки
- `main` — стабильная ветка. Пушить сюда напрямую ЗАПРЕЩЕНО.
- `feature/название-фичи` — для новой функциональности.
- `bugfix/название-бага` — для исправления ошибок.
- `docs/название` — для документации.

## Коммиты
Используем Conventional Commits:
- `feat: ...` — новая фича
- `fix: ...` — исправление бага
- `docs: ...` — документация
- `chore: ...` — рутина (настройка гита, зависимостей)

## Процесс слияния (Pull Request)
1. Создать ветку от `main`.
2. Сделать коммиты.
3. Запушить ветку на GitHub.
4. Создать Pull Request (PR) в `main`.
5. Получить аппрув (Code Review) от хотя бы одного участника команды.
6. Смержить PR.
