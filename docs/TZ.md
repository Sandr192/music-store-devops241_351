# Техническое задание: Музыкальный магазин

## 1. Назначение системы
Система представляет собой веб-приложение для учета музыкальных дисков, управления каталогом исполнителей, оформления продаж и отслеживания остатков на складе.

## 2. Категории пользователей
- **Гость**: просмотр каталога, поиск по жанрам и исполнителям.
- **Покупатель**: оформление заказов, просмотр истории покупок.
- **Администратор**: управление каталогом (добавление/редактирование альбомов и музыкантов), просмотр отчетов по продажам.

## 3. Основные сценарии
1. Администратор добавляет нового музыканта и его альбом в каталог.
2. Покупатель выбирает диск, добавляет в корзину и оформляет покупку.
3. Система проверяет остаток на складе и списывает его при успешной продаже.

## 4. Бизнес-правила (Ограничения)
- Нельзя продать диск, если его остаток на складе равен 0.
- Цена диска не может быть отрицательной.
- Продажа должна быть атомарной (если списание остатка не удалось, продажа не создается).

## 5. Сущности (Предварительная схема)
- `Musician` (Музыкант): id, имя, страна.
- `Album` (Альбом): id, название, год выпуска, цена, остаток, musician_id.
- `Genre` (Жанр): id, название.
- `Sale` (Продажа): id, album_id, количество, итоговая сумма, дата.

## Функциональные требования

### Роли пользователей

| Роль | Описание | Права |
|------|----------|-------|
| Гость | Неавторизованный пользователь | Просмотр каталога, поиск |
| Пользователь | Авторизованный покупатель | Просмотр, покупка, история заказов |
| Администратор | Управляющий магазином | Полный CRUD, отчёты, управление пользователями |

### Управление музыкантами

- Создание музыканта: имя, страна.
- Просмотр списка музыкантов и информации о конкретном музыканте.
- Редактирование данных музыканта.
- Удаление музыканта (каскадно удаляются его альбомы).
- Поиск музыкантов по имени и стране.

### Управление жанрами

- Создание жанра (уникальное название).
- Просмотр списка жанров.
- Редактирование и удаление жанра.
- Связь «многие-ко-многим» с альбомами.

### Управление альбомами

- Создание альбома: название, год выпуска, цена, остаток на складе, музыкант, жанры.
- Просмотр каталога альбомов с фильтрацией по жанру, музыканту, году.
- Редактирование альбома.
- Удаление альбома (запрещено, если есть продажи).
- **Бизнес-правило:** цена и остаток не могут быть отрицательными.

### Продажи

- Оформление продажи: выбор альбома, количество.
- **Бизнес-правило:** количество продажи > 0, итоговая цена >= 0.
- **Бизнес-правило:** нельзя продать больше, чем есть на складе.
- Автоматическое списание остатка при продаже.
- Просмотр истории продаж (только администратор).
- Формирование отчёта по продажам (лидеры продаж, выручка).

### Аутентификация и авторизация

- Регистрация нового пользователя.
- Вход по логину и паролю (JWT-токен).
- Хеширование паролей (bcrypt).
- Разграничение доступа: `admin_required` для защищённых эндпоинтов.
- Выход из системы.

### Отчёты и аналитика

- Список лидеров продаж (топ альбомов).
- Общая выручка за период.
- Остатки на складе (товары, заканчивающиеся).
- Количество проданных дисков по жанрам.
