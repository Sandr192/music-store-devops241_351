# Техническое задание: Музыкальный магазин

## 1. Назначение системы
Система представляет собой веб-приложение для учета музыкальных дисков, управления каталогом исполнителей, оформления продаж и отслеживания остатков на складе.

## 2. Категории пользователей
- **Гость**: просмотр каталога, поиск по жанрам и исполнителям.
- **Покупатель**: оформление заказов, просмотр истории покупок.
- **Администратор**: управление каталогом (добавление/редактирование альбомов и музыкантов), просмотр отчетов по продажам.

## 3. Основные сценарии
1. Администратор добавляет нового музыканта и его альбом в каталог.
2. Покупатель выбирает диск, добавляет в корзину и оформляет покупку.
3. Система проверяет остаток на складе и списывает его при успешной продаже.

## 4. Бизнес-правила (Ограничения)
- Нельзя продать диск, если его остаток на складе равен 0.
- Цена диска не может быть отрицательной.
- Продажа должна быть атомарной (если списание остатка не удалось, продажа не создается).

## 5. Сущности (Предварительная схема)
- `Musician` (Музыкант): id, имя, страна.
- `Album` (Альбом): id, название, год выпуска, цена, остаток, musician_id.
- `Genre` (Жанр): id, название.
- `Sale` (Продажа): id, album_id, количество, итоговая сумма, дата.
