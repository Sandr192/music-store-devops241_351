# Инфраструктура проекта «Музыкальный магазин» (ЛР2)

Документ описывает схему сети, параметры виртуальных машин и порядок восстановления после сбоев.

## 🗺️ Схема сети

*   **Host-only сеть:** `192.168.56.0/24` (шлюз Windows — `192.168.56.1`)
*   **Сервер приложения (lab2-app):** `192.168.56.10`
*   **Сервер БД (lab2-db):** `192.168.56.20`

## 🖥️ Виртуальные машины

### 1. lab2-app (сервер приложения)

| Параметр | Значение |
|----------|----------|
| OS | Debian 13 (без GUI) |
| IP | 192.168.56.10 |
| Пользователь SSH | labadmin (только по ключу, без пароля) |
| Приложение | FastAPI + Uvicorn |
| Порт приложения | **8000** |
| Директория проекта | /opt/music-store |
| Виртуальное окружение | /opt/music-store/.venv |
| Файл конфигурации (.env) | /etc/music-store/app.env |
| Пользователь приложения | musicstore (системный, без sudo) |
| Служба systemd | /etc/systemd/system/music-store.service |

### 2. lab2-db (сервер базы данных)

| Параметр | Значение |
|----------|----------|
| OS | Debian 13 (без GUI) |
| IP | 192.168.56.20 |
| Пользователь SSH | labadmin (только по ключу, без пароля) |
| PostgreSQL | версия 17 |
| Порт | 5432 (доступен только с 192.168.56.10) |
| Конфигурация | /etc/postgresql/17/main/ |
| Роль приложения | musicstore_app (пароль в credentials) |
| Роль миграций | musicstore_migrate (пароль в credentials) |

## 🔐 Правила безопасности

*   Приложение **не запускается от root** — используется системный пользователь `musicstore` без прав `sudo`.
*   Вход по SSH разрешён **только по ключам** (`labadmin`). Вход под `root` и по паролю запрещён.
*   Секреты (пароли БД, JWT-секрет) хранятся в `/etc/music-store/app.env` и не коммитятся в Git.
*   Подключение к PostgreSQL по сети разрешено только с IP сервера приложения (`192.168.56.10`).

## 🔥 Firewall

Правила сохранены в `/etc/iptables/rules.v4` и `/etc/iptables/rules.v6` на обеих машинах.
